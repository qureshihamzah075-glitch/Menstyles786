About MenStyle's

Our Website

MenStyle is a simple website made for men's fashion and accessories. It provides different ideas for clothing and accessories in one place.


Our Goal

Our goal is to make men's fashion simple, affordable and easy to understand. Users can explore clothing, watches, sunglasses, wallets, belts and more.


Project Information

This website is created using only HTML and CSS. It is a basic front-end project suitable for a BCA Semester 1 student.
